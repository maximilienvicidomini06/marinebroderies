Une gestion claire des titres financiers

Le module complete la comptabilite Odoo pour enregistrer les mouvements de titres, conserver leur identifiant ISIN et suivre les quantites ainsi que le prix moyen de chaque position.

1

Activez le mode financier

Activez le mode Produits financiers dans les parametres de Comptabilite, pour chaque societe concernee.

2

Referencez vos titres

Identifiez chaque titre dans les contacts comme produit financier et renseignez son code ISIN.

3

Rapprochez les operations

Saisissez la quantite lors du rapprochement bancaire et consultez automatiquement le prix unitaire calcule.

Fonctionnalites

  • Activation independante du suivi des produits financiers par societe.
  • Identification des titres avec un code ISIN normalise, valide et unique.
  • Affichage du code ISIN dans le nom du titre pour une selection fiable.
  • Saisie de la quantite de titres dans les vues de rapprochement bancaire, y compris la creation rapide.
  • Calcul automatique du prix unitaire a partir du montant bancaire et de la quantite.
  • Transmission de la quantite signee et du code ISIN vers les ecritures comptables de contrepartie.
  • Controle des donnees: quantite positive, montant non nul et titre financier obligatoire.

Grand livre produits financiers

Un rapport dedie affiche uniquement les titres financiers ayant des mouvements de quantite. Il permet de suivre chaque position par code ISIN et de controler son evolution.
