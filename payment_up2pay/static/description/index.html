Description

Compatible avec 3DSv2

Up2pay e-Transactions est la solution de paiement à distance dans un environnement sécurisé du Crédit Agricole pour accepter et gérer les achats réalisés sur votre boutique en ligne

  • Optimisez l’expérience d’achat de vos clients
  • Une page de paiement conçue pour améliorer votre taux de conversion
  • Encaissez en toute sérénité dans un environnement fiable et sécurisé pour limiter les risques de fraude
  • Pilotez vos performances en temps réel depuis le portail de gestion Vision Air
  • Optez pour une solution facile à installer
  • Un dispositif d’accompagnement pour vous aider à chaque étape

Installation et configuration

La configuration de Up2pay est simple, rapide et parfaitement intégrée à Odoo.
Pour installer Up2pay, Il suffit d'installer dans votre serveur PyCryptodome

Pour configurer Up2pay, Il suffit d'aller "Intermédiaires de paiement", choisir Up2pay
Entrez les informations suivants:

Félicitations, vous êtes prêt à accepter des paiements !

Méthode de paiement

Après avoir rempli les détails de l' expédition et de la facturation , la prochaine étape est de valider la commande. Vous pouvez voir Up2pay comme méthode de paiement. Sélectionnez-le et cliquez sur Payer maintenant. Après cela, vous serez redirigé vers le site de Up2pay.

Pages de paiement

Tout au long du processus de paiement, plusieurs pages s’affichent successivement.

Confirmation de commande

Une fois que vous entrez dans les détails du paiement correct et cliquez sur effectuer le paiement, le système sera redirigé vers Odoo. Vous obtenez l'accusé de réception de votre commande avec le numéro de commande.

Transaction de paiement

Dans le back-end, passer au " Transactions de paiement ". Tous les paiements effectués à l'aide de Up2pay sont enregistrés ici. Si vous ouvrez une transaction, il vous donnera les détails.
